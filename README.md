# TaskFlow — Менеджер задач

Веб-приложение для управления задачами с авторизацией. 
Полноценный CRUD с JWT-аутентификацией на FastAPI и ванильным фронтендом.

## Функциональность

- ✅ Регистрация и вход (JWT токены)
- ✅ Создание, просмотр, обновление и удаление задач
- ✅ Отметка выполнения (чекбокс)
- ✅ Фильтрация: Все / Активные / Выполненные
- ✅ Подсчёт оставшихся задач
- ✅ Адаптивный дизайн

## Технологии

| Компонент | Технология |
|-----------|------------|
| Бэкенд | Python + FastAPI |
| База данных | SQLite + SQLAlchemy |
| Аутентификация | JWT + bcrypt |
| Фронтенд | HTML + CSS + JavaScript (Vanilla) |
